# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: we treat everyone with respect, we accept constructive criticism,
and we do not tolerate harassment, insults, or discrimination of any kind.

To report unacceptable behavior, open a private Issue or contact the project
maintainer on Discord: `RubioKo#2533`.
