# Security / Seguridad

HiveScope is in design and documentation; there are no supported software releases.
Do not use it as the only copy of a file or send real keys or personal data in reports.

For a sensitive security report, use
[GitHub private vulnerability reporting](https://github.com/RubioKo/hivescope/security/advisories/new).
Public design questions belong in Issues. Full policy:
[English](docs/en/security.md).

HiveScope está en fase de diseño y documentación; no hay versiones de software con soporte.
No lo uses como única copia de un archivo ni envíes claves reales o datos personales en informes.

Para un informe de seguridad sensible, utiliza los
[informes privados de vulnerabilidad de GitHub](https://github.com/RubioKo/hivescope/security/advisories/new).
Las preguntas públicas de diseño van en Issues. Política completa:
[Español](docs/es/security.md).
